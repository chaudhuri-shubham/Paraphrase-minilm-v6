1. What is a synthetic key and when does it occur? How would you handle it?
Answer:
A synthetic key occurs when two or more tables share more than one common field.
Example: Table A + Table B both contain fields CustomerID and Date.
Qlik Sense creates a synthetic table to resolve compound keys — often causing performance issues.
Fixes:
Rename or alias fields
Concatenate tables
Create composite keys manually
Remove unnecessary fields


2. How does Set Analysis differ from normal filtering? Provide an example.
Answer:
Set Analysis applies predefined selections inside expressions, independent of user selections.
Example:
Copy code
Qlik
Sum({<Year={2024}>} Sales)
This always calculates 2024 sales even if the user selects a different year.
Normal filtering is based on UI selections and cannot override selections.

4. Explain ApplyMap() with an example.
Answer:
ApplyMap() works like a VLOOKUP.
Example:
Copy code



Map_Salesperson:
Mapping
LOAD ID, Name
FROM Sales.csv;

LOAD
SalesID,
ApplyMap('Map_Salesperson', SalesID, 'Unknown') as SalesPersonName;
It avoids joins → faster performance and cleaner model.

7. How do you create a Master Dimension and why is it important?
Answer:
Master Dimensions are reusable governed fields used across multiple charts.
Steps:
Open Master Items → Dimension → Create New
Select a field or write an expression
Example expression dimension:
Copy code
Qlik
=Year(Date)
Benefits: consistency, fewer errors, faster development


8. What is a Master Measure? Give an example.
Answer:
A Master Measure stores reusable expressions like metrics.
Example:
Copy code
Qlik
Sum(Sales)
Or with logic:
Copy code
Qlik
Sum({<Year={$(=Year(Today()))}>} Sales)
Using Master Measures improves governance and allows formatting + color settings.


9. Explain the difference between a Dimension and Measure with example.
Answer:
Dimension → descriptive fields used to slice data
Example: Region, Product, Month
Measure → numeric calculations aggregated on dimensions
Example:
Copy code
Qlik
Sum(Sales)
Avg(Discount)
Count(CustomerID)
A chart requires at least one dimension and one measure (except KPIs).

18. If data refreshes monthly and dashboard must compare to previous month automatically, how would you do it?
Answer:
Copy code



Sum({<Month = {"$(=Max(Month))"}>} Sales)

Sum({<Month = {"$(=Max(Month)-1)"}>} Sales)
✔ No manual selection needed
✔ Works even when next month arrives

24. You have a chart with two measures, but one measure ranges from 1 to 10,000 and the other from 1 to 10. The visual becomes distorted because the small measure becomes invisible.
How to show both clearly?
✅ Option A: Use Dual Axis
Works best in line/bar charts.
One axis handles the large measure, the other handles the small measure.
How:
Go to Chart → Appearance → Axes
Enable Secondary Axis for the smaller measure.
